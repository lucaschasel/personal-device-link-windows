# 0.13.0 接收端弹窗授权

两端建议使用同一版本。发现/控制协议为 7，剪贴板子协议为 2；不兼容更早协议。

## 使用流程

1. 打开两端桌面应用，在局域网设备列表连接，或先建立蓝牙链路再点击“连接蓝牙设备”。普通连接不接管键鼠，也不读取剪贴板。
2. 控制：主动方选择键盘、鼠标与快捷键适配，点击开始。接收端弹窗显示设备名称、系统、连接方式、地址和所需权限；点击“同意本次请求”后开始，无需控制码。
3. 文件：选择文件发送。接收端弹窗显示上述设备信息、文件名和大小；选择保存位置即同意该文件，也可以拒绝或稍后处理。已有文件不覆盖。
4. 剪贴板：主动方在连接后的可选功能中勾选共享。接收方无需预先开启开关；弹窗同意后双向同步新复制的文字、图片与文件，不输入配对码。旧内容须手动点击“同步当前内容”才发送。

两端均可发起请求，系统种类不决定方向。蓝牙首次使用仍需在操作系统设置完成设备配对；本版取消的是应用内的控制码与剪贴板配对码。

## 权限与退出

- 控制和剪贴板请求 60 秒内有效。拒绝、超时、断开、退出或撤回请求都不会授权。文件请求仍为 2 分钟。
- 默认允许显示控制请求；接收端可以“停止控制并关闭请求”，结束正在被控的会话并取消待处理控制请求。
- 控制中减少功能、关闭键鼠暂停不需要确认。新增键盘/鼠标，或在启用键盘时改变快捷键适配，需要接收方再次同意。等待前释放远端按键和按钮，主动方暂停捕获。
- 等待控制授权时取消，会关闭该控制连接；拒绝/超时也结束该连接。之后可重新连接请求。正常活动控制停止仍保留普通连接。
- 剪贴板的同意持续到本次共享会话结束。任一端取消勾选即可停止，失败或断开后不会自动恢复，重新共享必须再次确认。控制停止不自动结束剪贴板共享。
- 剪贴板中的后续敏感内容也会同步；它的授权包含文字、图片与复制文件。文件数量、大小和缓存限制保持原有规则，界面可查看。

## 弹窗信息

名称与 OS 来自对方声明，地址来自实际 TCP 连接。回环地址显示“蓝牙 / 本机桥接”，其他地址显示“局域网 / IP 直连”。现有蓝牙桥接以回环 TCP 交付数据，因此不能仅凭地址进一步证明蓝牙身份。

控制和剪贴板弹窗按队列显示，文件弹窗与它们互斥。收到新弹窗时尝试显示并聚焦应用窗口；操作系统可能限制窗口抢焦点。如果正在控制另一台电脑，Mac 按住 Control+Option、Windows 按住 Ctrl+Alt 操作本机窗口。

## 建议实机验收

1. 分别以局域网、蓝牙连接，在 Windows→Mac 和 Mac→Windows 两个方向检查设备信息与请求内容。
2. 控制先拒绝一次，确认没有输入接管；重新连接后同意键盘控制，再增加鼠标，检查再次弹窗；等待中取消，确认对端弹窗消失。
3. 文件先拒绝，再接收至新路径，核对文件名、大小、保存结果。
4. 只在一端勾选剪贴板，另一端同意，双向复制中文、图片和普通文件。关闭后重新发起，确认仍需新弹窗。
5. 请求等待超过 60 秒、断开蓝牙/网络、关闭应用时，确认没有迟到授权与残留按键。

自动化验证使用模拟输入、模拟剪贴板和回环 TCP，不触碰用户真实输入或剪贴板。各仓库分别执行本平台原生构建；真实权限和蓝牙射频行为仍需双机测试。
