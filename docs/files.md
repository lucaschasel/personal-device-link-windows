# 文件传输

两台受支持设备均可发送或接收文件，局域网和蓝牙使用相同的授权流程。

## 操作

1. 两台设备打开应用即开启接收服务，无需开启控制接收。先退出旧版本，避免占用 45832 端口。
2. 发送端连接对方后点击“选择文件并发送”，支持同系统与跨系统。每次选择一个普通文件，不支持文件夹。
3. 接收端弹出文件名、大小、发送方名称和实际网络地址。点击“选择位置并接收”，选择一个新的保存文件名。点击“稍后处理”后可在传输列表继续处理；取消系统保存对话框会保留请求，2 分钟内可重试。点击“拒绝”则不创建文件。
4. 传输列表显示字节数、百分比、平均速度。双方均可取消。传输到 100% 后还要等待 SHA-256 校验、落盘和确认，看到“已完成”才算成功。
5. 接收端显示保存路径，双方可展开 SHA-256 校验值。不自动打开收到的文件。

无需开始键鼠控制即可传文件。也可在已有键鼠会话期间传输；操作 Mac 对话框时建议先停止控制，或按住 Control+Option 使用本机鼠标（键盘仍属于远端）。停止键鼠控制、停止控制接收和断开页面中的控制连接都不会取消已开始的独立文件任务；使用对应文件的“取消传输”。关闭应用会取消文件任务并等待清理。

## 保存与边界

- 每个文件一个独立 TCP 连接，连接同一 45832 端口；文件控制消息也走该独立连接，键鼠长连接不承载文件数据。文件首帧 `file_offer` 携带文件子协议版本 1、设备、文件名、大小。
- 每次最多 1 MiB 缓冲，传输和 SHA-256 同时进行，不将文件整体载入内存。支持零字节文件，单文件上限 1 TiB，每台最多 4 个待确认或活动任务，保留最近 50 条记录（仅本次运行）。
- 只接受文件名，不接受对方指定的保存路径。拒绝路径分隔符、控制字符及不兼容的 Windows 文件名。设备名称由对方声明，实际 IP 会一同显示；只确认认识的设备。
- 使用接收者选择目录下随机 `.pdl-<UUID>.part` 临时文件。数据长度与 SHA-256 均通过后同步磁盘，再以“不覆盖”方式生成最终文件。目标预先存在或传输过程中出现同名文件时均不覆盖。
- 为保证最终文件不会覆盖既有文件，目标目录必须支持同卷硬链接，建议本机 NTFS/APFS。exFAT/FAT、部分网盘/网络盘可能不支持，会明确报错并清理临时文件，请先存到本机磁盘。取消、拒绝、普通断线、写盘/校验失败会清理临时文件；强制杀进程或断电可能留下 `.part`，确认应用已退出后可手动删除对应残留。
- 控制帧有总时间限制，传输读写有 15 秒无响应超时，等待接收确认上限 2 分钟。不支持断点续传，失败后重新选择文件。源文件在发送期间发生可检测的大小/修改时间变化会失败，请发送已保存且未继续修改的文件。
- TCP 尚未加密。SHA-256 用于核对传输内容完整性，不提供设备身份认证或抵御同网段攻击。只在受信任局域网使用。
- 最终确认报文可能因断网丢失：接收端已经显示完成时文件已保存，发送端可能显示失败。此时先核对接收端路径和 SHA-256，不要假定文件一定未送达。

## 双机验收

1. 在两个方向依次发送约 1 KiB、10 MiB、1 GiB 文件，包含中文和空格文件名，以及空文件。核对保存内容及两侧校验值。
2. 请求未确认前不应在目标目录出现文件；拒绝后无新文件。保存对话框取消后仍可重试；选择已有文件应提示换名，原文件不变。
3. 大文件传输期间分别从发送端和接收端取消，确认没有最终文件或残留 `.part`；重试成功。
4. 传输中断网、正常关闭接收程序，再重连重试。不要将强杀进程等同于正常退出清理。
5. 大文件传输期间继续测试键鼠移动和打字，并观察进度更新与应用内存。传输不应让控制通道失去心跳，但网络带宽、磁盘忙碌仍会影响体验。
6. 切换为 Wi-Fi 热点并断开互联网，重复两个方向的小文件及控制测试。编译依赖需要互联网，应用运行不依赖云服务。

可用系统工具额外校验：Windows `Get-FileHash -Algorithm SHA256 -LiteralPath '文件路径'`；Mac `shasum -a 256 '文件路径'`。

开发自动测试使用 Windows 上两个独立回环端点，设备标签 Mac/Windows 仅验证协议双向行为，不代表在 Mac 原生运行通过。1 GiB 测试单独执行并记录 Rust 堆内存分配上限；不包含 WebView、操作系统缓存或真实网络性能。详见 [测试与验证](testing.md)。

实现参考：[Tauri 原生文件对话框](https://v2.tauri.app/plugin/dialog/)、[RustCrypto SHA-2](https://docs.rs/sha2/0.10.9/sha2/)。
